## How to run

One question per fresh session, see METHOD.md. Run them in sequence and the later ones inherit context, at which point the token numbers stop meaning anything.

| Scoring mode | Scored how |
|---|---|
| `exact` | String or value match against the key |
| `set` | Recall and precision reported **separately**, never collapsed into one number |
| `empty_set` | Pass needs the empty set **and** evidence the agent checked, not a guess |
| `prose` | Judgement |
