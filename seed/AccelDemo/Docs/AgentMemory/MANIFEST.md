Generated by the AgentMemoryDump commandlet. Do not hand edit.

**What this is for.** Everything in this directory is generated, and a generated
file that has gone stale looks exactly like one that has not. Check this before
trusting an answer that turns on a recent change.

**This is the one artefact that changes on every run, deliberately.** Every other
file here is byte-identical when regenerated from unchanged source, which is what
makes them committable: a diff means the code moved. This file carries a timestamp
because recording *when* is its entire job, so it is excluded from that rule and
from the determinism check. Do not commit it expecting a clean diff.

**Artefact format is the one to check after a plugin update.** It is the shape of
these files, not their content: when it moves, an artefact set written before the
move is wrong in ways that reading it will not show. `/ue-memory-stack:doctor`
compares it against the plugin installed here and says so. A set written before
this row existed carries no format at all, which is itself the answer.

**Compare engines on the compatible changelist, not the changelist.** A source
build never stamps the latter, so it reads 0 on every engine and tells you
nothing about which one produced these files.

**No project revision.** A project that is not under version control has no
revision to record, and a field claiming one would be invented. Staleness is
checked by comparing these files' timestamps against the newest reflected source
file, which `scripts/Update-MemoryStack.ps1 -Stages Verify`
does automatically and fails on.

**No line numbers anywhere in these artefacts.** The reflection system records
none, for any field. `classes/<Class>.md` names the declaring header; for a line,
grep that header, or use `engine_api_search` with `kind='comment'`, which carries
`<path>:<line>` for every documented declaration.
