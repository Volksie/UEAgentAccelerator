# Input mapping contexts

Generated by the AgentMemoryDump commandlet. Do not hand edit.

Key-to-action bindings, read from the loaded assets. **This is the only tier that
loads**: a binding lives in no asset registry tag, so nothing else in this stack can
say what any key does. There are few enough contexts that the load is free.

**A controller label is not a key.** A person says "the cross button" and the
asset says `Gamepad_FaceButton_Bottom`. That translation lives in the engine, in
`EKeys::GetGamepadDisplayName`, and it is **per label set**. Two things follow that
a reader will otherwise get wrong:

- **Not every console has a label set.** `EConsoleForGamepadLabels` names only some,
  and a newer console uses its predecessor's. A row claiming its own set would be invented.
- **"Gamepad X" is ambiguous.** It is `Gamepad_FaceButton_Bottom` under one console's
  labels and `Gamepad_FaceButton_Left` under another's - two different keys, bound here to
  **different actions**. Resolve the label set before resolving the label.
